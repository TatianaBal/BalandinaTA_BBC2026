# Менеджер задач (Task Manager) с графическим интерфейсом и базой данных

Десктопное приложение для управления списком повседневных задач с поддержкой приоритетов и автоматическим сохранением данных в локальную базу **SQLite**. Проект реализован в двух вариантах графического интерфейса: на **PyQt6** и на встроенной библиотеке **Tkinter**.

## Основной функционал

* **Добавление задач:** ввод текста задачи с проверкой на пустое поле.
* **Выбор приоритета:** назначение уровня важности (`Высокий`, `Средний`, `Низкий`).
* **Отметка о выполнении:** интерактивные чекбоксы, которые зачеркивают текст выполненной задачи и обновляют её статус в базе данных.
* **Гибкая очистка списка:**
  * *«Удалить выполненные»* — удаляет только отмеченные задачи.
  * *«Очистить все»* — полностью очищает список и таблицу в базе данных.
* **Постоянное хранение данных:** все задачи и их статусы автоматически загружаются при запуске программы и сохраняются при любых изменениях.

## Технологии

* **Язык программирования:** Python 3.12+
* **Графический интерфейс (GUI):** PyQt6 и Tkinter
* **База данных:** SQLite3 (`sqlite3`)

## Структура базы данных

При первом запуске приложение автоматически создает файл базы данных (`.db`) и таблицу `tasks` со следующей структурой:

| Поле | Тип данных | Описание |
| :--- | :--- | :--- |
| `id` | `INTEGER PRIMARY KEY AUTOINCREMENT` | Уникальный идентификатор задачи |
| `title` | `TEXT NOT NULL` | Текст (название) задачи |
| `priority` | `TEXT NOT NULL` | Уровень приоритета (`высокий`, `средний`, `низкий`) |
| `is_done` | `INTEGER DEFAULT 0` | Статус выполнения (`0` — активна, `1` — выполнена) |

## Установка и запуск

1. **Клонируйте репозиторий или скачайте файлы проекта:**
   ```bash
   git clone <ссылка-на-ваш-репозиторий>
   cd <папка-проекта>
   ```

2. **Запуск версии на PyQt6 (`interfacedb.py`):**
   Сначала установите библиотеку PyQt6:
   ```bash
   pip install PyQt6
   ```
   Затем запустите приложение:
   ```bash
   python interfacedb.py
   ```

3. **Запуск версии на Tkinter (`interfacedb2.py`):**
   Установка сторонних библиотек не требуется, достаточно выполнить:
   ```bash
   python interfacedb2.py
   ```

## Структура проекта

* `interfacedb.py` — версия приложения с графическим интерфейсом на **PyQt6** и подключением к SQLite.
* `interfacedb2.py` — версия приложения с графическим интерфейсом на **Tkinter** и подключением к SQLite.
* `.gitignore` — список исключений для Git (игнорирует локальные файлы `.db` и кэш Python).
* `README.md` — документация проекта.
