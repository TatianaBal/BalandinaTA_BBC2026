# Интерактивный тренажёр по методам строк в Python (`5.py`)

Консольное учебное приложение на языке Python, демонстрирующее основные встроенные методы работы со строками (`str`) и форматирования текста. Программа разделена на 5 интерактивных уровней сложности.

## Основной функционал

* **Уровень 1 — Изменение регистра:** преобразование введённой строки с помощью методов `.upper()` (все заглавные), `.lower()` (все строчные) и `.capitalize()` (первая буква заглавная, остальные строчные).
* **Уровень 2 — Поиск и замена подстрок:** определение индекса первого вхождения слова (`.find()`), замена фрагментов текста на пользовательское слово (`.replace()`) и подсчёт количества символов (`.count()`).
* **Уровень 3 — Разбиение и склейка строк:** преобразование строки с разделителями в список (`.split()`) и обратная сборка списка в единую строку через новый разделитель (`.join()`).
* **Уровень 4 — Проверки содержимого, очистка и форматирование:**
  * проверка строки на наличие только цифр (`.isdigit()`) или только букв (`.isalpha()`);
  * удаление крайних пробелов (`.strip()`);
  * выравнивание текста по краям и центру, заполнение пустот символами и обрезка длины через `f-строки`.
* **Уровень 5 — Цепочка методов (Method Chaining):** комплексная очистка и нормализация строки за один проход (последовательное применение `.strip()`, `.replace()` и `.lower()`).

## Технологии

* **Язык программирования:** Python 3.x (используются только встроенные методы типа `str`, `f-строки` и условные операторы `if`, установка сторонних библиотек не требуется).

## Установка и запуск

1. **Клонируйте репозиторий или скачайте файл скрипта:**
   ```bash
   git clone <ссылка-на-ваш-репозиторий>
   cd <папка-проекта>
   ```

2. **Запустите программу в терминале:**
   ```bash
   python 5.py
   ```
