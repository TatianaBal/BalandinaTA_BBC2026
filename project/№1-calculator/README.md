# Учебные проекты на Python: калькуляторы (от базового синтаксиса до ООП)

Набор консольных скриптов на языке Python, демонстрирующий поэтапное освоение программирования: от простых линейных программ с условными операторами до использования функций, бесконечных циклов и объектно-ориентированного программирования (ООП) с применением классов и методов.

## Содержание репозитория

1. **`<файл_1>.py` — Базовый арифметический калькулятор**
   * Линейный скрипт на условных операторах `if`.
   * Запрашивает два целых числа и знак операции (`+`, `-`, `*`, `/`), после чего выводит результат вычисления.

2. **`<файл_2>.py` — Калькулятор на отдельных функциях**
   * Вынесение каждой математической операции в самостоятельную функцию (`f`, `g`, `d`, `e`) с использованием строк документации (`docstrings`).

3. **`<файл_3>.py` — Калькулятор с единой управляющей функцией**
   * Объединение всей логики выбора операции и расчёта внутри одной функции `f(a, b)`.

4. **`<файл_4>.py` — Циклический калькулятор**
   * Интерактивный режим работы на базе бесконечного цикла `while True`, позволяющий выполнять серию расчётов подряд без перезапуска программы.

5. **`calculator.py` — Объектно-ориентированный калькулятор**
   * Реализация калькулятора через класс `Calculator`, инкапсулирующий арифметические действия в виде методов (`h`, `g`, `d`, `e`) с возвратом значений через `return`.

6. **`credit.py` — Кредитный калькулятор (ООП)**
   * Прикладной скрипт с классом `Credit` (конструктор `__init__` и метод расчёта `payment()`).
   * Вычисляет ежемесячный аннуитетный платёж на основе суммы кредита, годовой процентной ставки и срока в годах с округлением результата до копеек.

## Технологии

* **Язык программирования:** Python 3.x
* **Инструменты:** стандартная библиотека Python (установка сторонних пакетов через `pip` не требуется).

## Установка и запуск

1. **Клонируйте репозиторий или скачайте файлы проекта:**
   ```bash
   git clone <ссылка-на-ваш-репозиторий>
   cd <папка-проекта>
   ```

2. **Запустите любой из скриптов через терминал:**
   ```bash
   # Арифметические калькуляторы (версии 1–4)
   python <файл_1>.py
   python <файл_2>.py
   python <файл_3>.py
   python <файл_4>.py

   # Арифметический калькулятор на классах (ООП)
   python calculator.py

   # Кредитный калькулятор на классах (ООП)
   python credit.py
   ```

## Примеры работы

**Арифметический калькулятор (`calculator.py`):**
```text
введите первое число: 10
введите второе число: 5
знак операции: *
50
```

**Кредитный калькулятор (`credit.py`):**
```text
сумма кредита: 1000000
годовая процентная ставка: 12
на сколько лет: 5
платеж в месяц: 22244.45
```
