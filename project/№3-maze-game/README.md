# Консольная текстовая RPG-игра «Лабиринт» (`labirint.py`)

Консольная приключенческая игра на языке Python с процедурной генерацией карты, туманом войны, инвентарём и пошаговыми событиями. Главная цель игрока — исследовать подземелье, найти ключ и добраться до выхода, сохранив очки здоровья (HP).

## Основной функционал

* **Процедурная генерация уровня:** при каждом запуске создаётся случайное поле размером от `5x5` до `15x15` клеток с взвешенным распределением комнат (пустые комнаты, сундуки, монстры и ловушки), а также случайным расположением ключа и выхода.
* **Туман войны и карта:** изначально игроку видна только стартовая клетка (`S`), остальные клетки скрыты (`?`) и открываются по мере исследования.
* **Система инвентаря и предметов:**
  * *Меч* — позволяет победить монстра в бою;
  * *Броня* — защищает от атаки монстра;
  * *Золото* — позволяет откупиться от монстра;
  * *Зелье* — восстанавливает `+1 HP` при использовании.
* **Случайные события в комнатах:**
  * **Сундук (`C`):** добавляет случайный предмет в инвентарь.
  * **Монстр (`M`):** предлагает выбор тактики (сражаться, защищаться, откупиться или отступить с потерей здоровья).
  * **Ловушка (`T`):** забирает случайный предмет из инвентаря или отнимает `1 HP`, если рюкзак пуст.
  * **Ключ (`K`) и Выход (`E`):** для победы необходимо сначала подобрать ключ, а затем наступить на клетку выхода.

## Управление и обозначения

* **Движение:** `w` (вверх), `s` (вниз), `a` (влево), `d` (вправо).
* **Действия:** `h` (выпить зелье здоровья), `i` (просмотреть инвентарь).
* **Символы на карте:** `*` — игрок, `S` — старт, `.` — пусто, `C` — сундук, `M` — монстр, `T` — ловушка, `K` — ключ, `E` — выход, `?` — неизведанная клетка.

## Технологии

* **Язык программирования:** Python 3.12+
* **Библиотеки:** встроенный модуль `random` (установка сторонних пакетов не требуется).

## Установка и запуск

1. **Клонируйте репозиторий или скачайте файл игры:**
   ```bash
   git clone <ссылка-на-ваш-репозиторий>
   cd <папка-проекта>
   ```

2. **Запустите игру в терминале:**
   ```bash
   python labirint.py
   ```
