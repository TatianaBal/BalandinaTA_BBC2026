# Менеджер задач (Task Manager) с графическим интерфейсом

Десктопное приложение для создания и управления списком повседневных задач с поддержкой выбора приоритетов. Проект реализован в двух вариантах графического интерфейса (без подключения базы данных, с хранением списка в оперативной памяти во время сеанса): на **PyQt6** и на встроенной библиотеке **Tkinter**.

## Основной функционал

* **Добавление задач:** ввод названия задачи с проверкой на пустое поле и выводом предупреждения.
* **Выбор приоритета:** назначение уровня важности (`Высокий`, `Средний`, `Низкий`) с помощью переключателей.
* **Отметка о выполнении:** интерактивные чекбоксы, которые визуально зачеркивают текст выполненной задачи.
* **Очистка списка:** удаление всех добавленных задач одной кнопкой *«Очистить все»*.

## Технологии

* **Язык программирования:** Python 3.12+
* **Графический интерфейс (GUI):** PyQt6 и Tkinter

## Установка и запуск

1. **Клонируйте репозиторий или скачайте файлы проекта:**
   ```bash
   git clone <ссылка-на-ваш-репозиторий>
   cd <папка-проекта>
   ```

2. **Запуск версии на PyQt6 (`interface.py`):**
   Сначала установите библиотеку PyQt6:
   ```bash
   pip install PyQt6
   ```
   Затем запустите приложение:
   ```bash
   python interface.py
   ```

3. **Запуск версии на Tkinter (`interface2.py`):**
   Установка сторонних библиотек не требуется, достаточно выполнить:
   ```bash
   python interface2.py
   ```

## Структура проекта

* `interface.py` — версия приложения с графическим интерфейсом на **PyQt6**.
* `interface2.py` — версия приложения с графическим интерфейсом на **Tkinter**.
* `.gitignore` — список исключений для Git (игнорирует кэш Python и настройки редактора).
* `README.md` — документация проекта.
