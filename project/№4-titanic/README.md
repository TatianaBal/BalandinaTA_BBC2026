# Анализ данных пассажиров «Титаника» (`titanic.py`)

Скрипт на языке Python для разведочного анализа данных (EDA), очистки датасета и статистических расчётов на основе таблицы `tested.csv` с использованием библиотек **Pandas** и **NumPy**.

## Что делает скрипт

* **Первичный осмотр данных:** вывод первых/последних строк, размерности таблицы, списка столбцов, типов данных и базовой статистики по числовым и категориальным признакам.
* **Обработка пропусков (Data Cleaning):**
  * заполнение пропущенных значений возраста (`Age`) медианным значением со сравнением статистики до и после обработки;
  * удаление строк с пустым портом посадки (`Embarked`);
  * удаление столбца `Cabin`, так как доля пропусков в нём превышает 50%.
* **Векторные вычисления на NumPy:** расчёт общей доли выживших, статистики выживаемости и среднего возраста в разрезе пола, а также минимальной/максимальной стоимости билета.
* **Фильтрация и группировка (Pandas):** выборки пассажиров по заданным условиям (класс каюты, возраст, пол, порт посадки, стоимость билета выше средней) и агрегация статистики через `groupby()`.
* **Экспорт результатов:** сохранение очищенного датасета в `titanic_processed.csv` и сводной таблицы статистики в `titanic_statistics.csv`.

## Технологии

* **Язык программирования:** Python 3.12+
* **Библиотеки:** `pandas`, `numpy`

## Установка и запуск

1. **Установите необходимые библиотеки:**
   ```bash
   pip install pandas numpy
   ```

2. **Убедитесь, что исходный датасет `tested.csv` находится в одной папке со скриптом, и запустите анализ:**
   ```bash
   python titanic.py
   ```

## Структура проекта

* `titanic.py` — основной скрипт очистки и анализа данных.
* `tested.csv` — исходный набор данных.
* `titanic_processed.csv` — очищенный датасет (создаётся автоматически после запуска).
* `titanic_statistics.csv` — сводная таблица статистики по классам и полу (создаётся автоматически).
* `README.md` — документация проекта и ответы на контрольные вопросы.

## Выводы по работе (Часть VIII)

**43. Какие признаки содержали наибольшее количество пропусков?**  
Наибольшее количество пропусков содержалось в столбце `Cabin` (327 пропусков из 418, около 78,2%) и в столбце `Age` (86 пропусков, около 20,6%). Также в исходной таблице присутствовал 1 пропуск в столбце `Fare`, тогда как в `Embarked` пропусков не было.

**44. Как обработка пропусков повлияла на размер данных и статистику возраста?**  
* **Размер данных:** количество строк не изменилось (осталось 418, так как пустых значений в `Embarked` не было), а количество столбцов уменьшилось с 12 до 11 после удаления столбца `Cabin` (доля пропусков > 50%).
* **Статистика возраста:** количество известных значений выросло с 332 до 418. Медиана (27.00), минимум (0.17) и максимум (76.00) не изменились. Среднее арифметическое незначительно снизилось (с 30.27 до 29.59), а стандартное отклонение уменьшилось (с 14.18 до 12.70), так как заполнение пропусков медианой уменьшило общий разброс значений.

**45. Как различалась выживаемость мужчин и женщин?**  
В используемом наборе данных (`tested.csv`) выживаемость женщин составила **100%** (152 из 152), а мужчин — **0%** (0 из 266). Общий процент выживших составил **36,36%**.

**46. В каком классе наблюдалась наибольшая доля выживших?**  
Наибольшая доля выживших наблюдалась в **1-м классе** (`Pclass = 1`) — **46,73%** (во 2-м классе — 32,26%, в 3-м классе — 33,03%), так как среди пассажиров первого класса была самая высокая доля женщин.

**47. Какие возможности Pandas и NumPy оказались наиболее полезными?**  
* **Pandas:** удобная загрузка и сохранение CSV-файлов (`read_csv`, `to_csv`), поиск и заполнение пропусков (`isnull`, `fillna`, `dropna`), фильтрация по сложным логическим условиям и группировка данных с агрегацией (`groupby`, `agg`).
* **NumPy:** быстрое вычисление статистических показателей (`mean`, `std`, `min`, `max`) и фильтрация массивов с помощью логических масок.
